Multibott

A desktop utility for preparing and publishing a user's own video content to TikTok.

What Multibott does

Multibott helps an authorized user organize prepared video files, create captions, schedule uploads, and publish content to the TikTok account that the user explicitly connects through TikTok's authorization flow.

User control

The user chooses which TikTok account to connect and can revoke access through TikTok. Multibott does not ask for or store the user's TikTok password.

About TikTok integration

Multibott uses TikTok's official developer interfaces where available. TikTok is a trademark of its respective owner. Multibott is an independent project and is not affiliated with or endorsed by TikTok.
