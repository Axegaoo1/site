Privacy Policy

Last updated: September 16, 2026

1. Overview

Multibott is a desktop utility that helps users prepare and publish their own video content to TikTok after the user explicitly authorizes access to a TikTok account.

2. Information used by the application

When a user connects TikTok, Multibott may receive account identifiers, basic profile information, authorization tokens, and permissions granted by the user through TikTok's OAuth flow.

3. Local storage

The current desktop version stores configuration data, publication state, and TikTok authorization tokens locally on the user's computer. The application does not require the user's TikTok password.

4. How information is used

Information received through TikTok is used only to identify the connected account, maintain authorization, upload content requested by the user, and display basic connection status.

5. Sharing

Multibott does not sell personal information. Data is transmitted to TikTok only as necessary to use TikTok features requested by the user.

6. Revoking access

Users can revoke Multibott's TikTok access using TikTok's account and security settings. Users can also delete locally stored Multibott configuration and token files from their computer.

7. Security

Users should keep authorization tokens, client secrets, and configuration files private and should not upload them to public repositories or share them with other people.

8. Changes

This policy may be updated when Multibott's features or data practices change. The date at the top of this page will be updated when material changes are made.
